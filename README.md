## ✨ Key Capabilities & Highlights

### 🥗 1. Goal-Adaptive Indian Vegetarian Diet Engine
- **Goal Personalization**:
  - **🔥 Weight Loss / Fat Loss**: High protein-to-calorie density, low-carb evening meals, caloric deficit calibration.
  - **💪 Muscle Gain / Hypertrophy**: Clean complex carbs, plant proteins (Paneer, Tofu, Soya, Chana), and lean surplus macros.
  - **🌸 PCOS / PCOD Support**: Low-glycemic index (Low-GI) nutrition to regulate insulin and cortisol sensitivity.
  - **🩸 Iron Boost**: Non-heme iron paired with Vitamin C synergy.
- **15-Day Continuous Horizon**: 15 distinct days of non-repeating meals with Google AI Mode search redirects for comprehensive ingredient & cooking breakdowns.

### 🛒 2. Smart 7-Day Weekly Grocery Checklist
- Automatically consolidates weekly supermarket packaging quantities (e.g. *Fresh Paneer ~500g*, *Curd 1kg tub*, *Spinach 2 fresh bunches*, *Tomatoes 1kg*, *Rolled Oats 500g*).
- **1-Tap WhatsApp / Notes Copy**: Formats the list with checkboxes (`▫️ / ✅`) and categories ready to share.
- Real-time shopping cart progress tracker with checkmark physics.

### 🏋️ 3. Goal-Driven Workout Protocols & In-Card Stopwatch
- **1-Tap Environment Filter**: Toggle between **`🏡 Home Workout (Light & Calisthenics)`** and **`🏋️ Gym Protocol (Weights & Machines)`**.
- **In-Card Rest Stopwatch**: `⏱️ 45s / 60s Rest` countdown with animated circular SVG timer ring and Web Audio completion chimes.
- **Form Coaching**: Step-by-step technique tips, easier/harder exercise progressions, and 1-tap **`▶ Video Tutorial ↗`** YouTube links.

### 📊 4. Health Intelligence Suite (Insights)
- **Metabolic Discipline Score**: 0–100% weekly habit adherence gauge with tier status (*🌟 Elite Tier*, *📈 Consistent*, *🌱 Building*).
- **Goal Trajectory & Timeline Projection**: Real-time roadmap with **Estimated Weeks to Target** calculation ($0.5\text{ kg/week}$ for fat loss, $0.25\text{ kg/week}$ for muscle gain).
- **7-Day Ritual Completion Flow**: Interactive daily rhythm bar charts.
- **Actionable AI Protocol Insights**: Context-aware coaching cards for protein pacing, front-loaded daytime hydration, and circadian sleep lock.
- **30-Day Activity Heatmap Grid**: High-density GitHub-style consistency matrix with historical drill-down.

### 📱 5. iOS 18 & visionOS Glassmorphic UI
- Ambient aura fluid mesh lighting (`auraShift1` & `auraShift2`) with 130px blur.
- Tactile spring physics (`scale(0.975)`) on all cards, tiles, and navigation items.
- Dynamic Island notifications with zero idle intrusion.
- Floating capsule bottom navigation with bouncy micro-animations.

## 🚀 Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/bhanushamdasani/HealthyHabits.git
cd HealthyHabits

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Run automated test suite
npm run test

# 5. Build production bundle
npm run build
```
